❓ How to use this tool ▼

What does this tool do?

This tool runs the ScratchSense rule-based checker suite against a Scratch project file (.sb3). It does NOT run the LLM analysis layer — LLM findings are excluded from this automated annotation.

For the technical body study:

  • Run this tool against each of the 20–30 corpus projects before running ScratchSense interactively
  • This establishes the gold standard baseline for comparison with interactive results
  • The score summary cards provide the numbers that go into Table 6.1 (body study) and Table 6.3 (user study)

For the user study:

  • Run this tool against each participant's saved .sb3 file (both tool-condition and control-condition)
  • This produces paired quality scores for analysis
  • Use the CSV export for the Appendix D annotation spreadsheet

Export formats:

  • Copy JSON: Copies the complete findings array as formatted JSON for analysis or integration
  • Download CSV: Produces one row per finding instance with columns: file, sprite, dimension, checker, severity, description. This is the format needed for the Appendix D annotation spreadsheet

Checkers included:

The rule-based analysis runs 28 checker modules covering:

  • Correctness: Script structure, variable initialization, event handling, cloning logic
  • Performance: Nesting depth, polling loops, broadcast optimization
  • Maintainability: Script length, naming conventions, dead blocks, code smell patterns

Empty results:

If a project has no findings, the tool shows a "No issues detected" banner. This is valid output — not all projects violate any rules.
